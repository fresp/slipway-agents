# Examples

This directory contains reference implementations generated by the `bootstrap-from-prd` skill.

## How to use these examples

Examples are reference material only. Use them to calibrate:

- **Writing tone** — direct, declarative, no filler
- **Level of detail** — how much to write per section, per field
- **Document structure** — section ordering, heading style, formatting conventions
- **Consistency patterns** — how a term used in one doc appears in all others

## What NOT to do with examples

Do not copy:

- Product names or domain names
- Service names or service counts
- Architecture patterns or topology decisions
- Technology stack choices
- API paths, field names, or business rules
- ADR content

Unless the PRD you are generating from explicitly requires any of the above.

## Available examples

### `managed-waba/`

A BSP-grade WhatsApp Business API management platform.

Context: multi-service architecture with a control plane / data plane separation, a transparent proxy pattern, and an async webhook delivery system. Good reference for:

- Systems with strict external API compatibility requirements
- Architectures with a clear proxy/pass-through service
- Queue-based async worker patterns
- Platforms where business state lives in an external system (Meta), not the platform itself

Generated engineering docs (`02`–`10`) are in English. When generating docs from a PRD in another language, produce all engineering output in English unless the user specifies otherwise.
